# AirScan Bridge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the iX500 as an eSCL/AirScan network scanner from inside the existing daemon, with client-driven scan settings and the Scan button still working.

**Architecture:** A std-only HTTP server and a small eSCL layer translate ScanJobs into the existing SCSI capture path. A shared scan lock serialises button scans and eSCL jobs. Bonjour advertising uses `mdns-sd`; jobs stream JPEG pages as they are read, or one PDF when the scan finishes, and every job also writes the usual PDF to the output directory.

**Tech Stack:** Rust 2024, std TCP/UDP and threads, `clap`, `getrandom`, `mdns-sd` 0.21. Tests use the loopback fake scanner in `tests/support`.

**Spec:** `docs/superpowers/specs/2026-11-01-airscan-design.md`

## Global Constraints

- `--airscan` conflicts with `--once`; AirScan is off by default.
- `--airscan-port` defaults to 8090; port 0 is allowed for tests.
- Only one scanner use at a time, across the button and eSCL. The scan lock is shared.
- JPEG bytes are never re-encoded. PDFs embed the original JPEGs with `/Rotate 180`.
- Delivered JPEG pages carry a 36-byte EXIF APP1 segment with Orientation 3.
- Every completed eSCL job writes the usual PDF; a cancelled job writes nothing.
- Capabilities: RGB24 only, `image/jpeg` and `application/pdf`, resolutions 150/200/300/600, maximum region 2612 x 4407 in 1/300 inch.
- HTTP head limit 16 KiB, body limit 1 MiB, XML depth limit 8, 256 elements, 4096 text bytes per node.
- To one dependency: `mdns-sd = "0.21"`. Nothing else.
- Status is served from cached state and never opens a SCSI connection.
- eSCL version in XML and TXT is `2.63`.

## Review Focus

1. A client scan region in the wrong units or larger than the platen must be clamped, not sent raw. Tests: Task 4 clamp test, Task 6 E9/D4 assertion.
2. Unsupported color mode, source or format must return 409, never a silently different scan. Tests: Task 4 parser tests, Task 6 409 test.
3. A cancel or client disconnect must release the scanner (D6), leave no half PDF, and let the next job run. Test: Task 6 cancel test.
4. A button press, power-off or busy scanner during an eSCL request must yield 503/409, never two scan connections. Tests: Task 5 lock test, Task 6 busy and no-session tests.
5. Hostile or broken HTTP/XML (oversized head or body, bad Content-Length, deep XML, unknown entity) must return 400/413 and keep the daemon alive. Tests: Task 3 limits tests, Task 4 malformed tests.

```rust
pub const MAX_HEAD: usize = 16 * 1024;
pub const MAX_BODY: usize = 1024 * 1024;

pub struct Request {

}

pub enum RequestError {

}

pub struct Response {
    pub status: u16,
    pub content_type: Option<&'static str>,
    pub body: Vec<u8>,
    pub headers: Vec<(String, String)>,
}
impl Response {
    pub fn empty(status: u16) -> Self;
    pub fn xml(body: String) -> Self;                       // 200, text/xml
    pub fn bytes(status: u16, content_type: &'static str, body: Vec<u8>) -> Self;
    pub fn header(self, name: &str, value: String) -> Self;

pub fn read_request(stream: &mut TcpStream) -> Result<Request, RequestError>;
pub fn write_response(stream: &mut TcpStream, head_only: bool, response: &Response) -> io::Result<()>;
```

Parsing rules: read the head byte by byte until `\r\n\r\n`, capped at 16 KiB; strip the query from the target; require `HTTP/1.x`; lowercase header names; `Content-Length` over 1 MiB is `TooLarge`; `Transfer-Encoding` other than `identity` is malformed; write `HTTP/1.1 100 Continue\r\n\r\n` before reading the body when `Expect` is `100-continue`. A stream that ends before the first byte is `Eof`; a head that ends before its terminator is `Malformed`. Responses always send `Server: freejitsu`, `Content-Length`, `Connection: close`, and omit the body when `head_only`.

```rust
use freejitsu::http::{Request, RequestError, Response, read_request, write_response};

fn parse_on_loopback(input: &[u8]) -> Result<Request, RequestError> {
    let listener = TcpListener::bind(("127.0.0.1", 0)).unwrap();
    let addr = listener.local_addr().unwrap();
    let writer = thread::spawn(move || {
        let mut stream = TcpStream::connect(addr).unwrap();
        stream.write_all(input).unwrap();
        thread::sleep(Duration::from_millis(100));
    });
    let (mut server, _) = listener.accept().unwrap();
    let request = read_request(&mut server);
    writer.join().unwrap();
    request
}

#[test]
fn reads_a_get_request() {

    .unwrap();

    assert_eq!(request.path, "/eSCL/ScannerStatus");
```

```rust
pub struct HttpResponse {
    pub status: u16,
    pub headers: Vec<(String, String)>,
    pub body: Vec<u8>,
}

impl HttpResponse {
    pub fn header(&self, name: &str) -> Option<&str> {
        self.headers
            .iter()
            .find(|(key, _)| key == name)
            .map(|(_, value)| value.as_str())
    }
}

pub fn http_request(addr: std::net::SocketAddr, request: &[u8]) -> HttpResponse {
    let mut stream = TcpStream::connect(addr).expect("connect http");
    stream.write_all(request).expect("write http");
    let mut raw = Vec::new();
    stream.read_to_end(&mut raw).expect("read http");
    let split = raw
        .windows(4)
        .position(|window| window == b"\r\n\r\n")
        .expect("http head");
    let head = std::str::from_utf8(&raw[..split]).expect("http head utf8");
    let mut lines = head.split("\r\n");
    let status = lines
        .next()
        .and_then(|line| line.split_whitespace().nth(1))
        .and_then(|word| word.parse().ok())
        .expect("http status");
    let headers = lines
        .filter_map(|line| line.split_once(':'))
        .map(|(key, value)| (key.to_ascii_lowercase(), value.trim().to_string()))
        .collect();
    HttpResponse {
        status,
        headers,
        body: raw[split + 4..].to_vec(),
    }
}

pub fn http_get(addr: std::net::SocketAddr, path: &str) -> HttpResponse {
    http_request(
        addr,
        format!("GET {path} HTTP/1.1\r\nHost: {addr}\r\nConnection: close\r\n\r\n").as_bytes(),
    )
}

pub fn http_post(addr: std::net::SocketAddr, path: &str, body: &[u8]) -> HttpResponse {
    let head = format!(
        "POST {path} HTTP/1.1\r\nHost: {addr}\r\nContent-Type: text/xml\r\nContent-Length: {}\r\nConnection: close\r\n\r\n",
        body.len()
    );
    let mut request = head.into_bytes();
    request.extend_from_slice(body);
    http_request(addr, &request)
}

pub fn http_delete(addr: std::net::SocketAddr, path: &str) -> HttpResponse {
    http_request(
        addr,
        format!("DELETE {path} HTTP/1.1\r\nHost: {addr}\r\nConnection: close\r\n\r\n").as_bytes(),
```

- [ ] **Step 4: Implement jobs in `src/airscan.rs`**

- `Job` with `id` (16 random bytes as hex, version 4 bits), `format`, `created`, and `Mutex<JobData> + Condvar`, plus `AtomicBool` cancel.
- `JobData { state, images, delivered, docs: VecDeque<Vec<u8>>, finished }`.
- `POST`: parse settings, clone the session, `try_lock` the scan lock, create and store the job, spawn the job thread, then wait up to 60 seconds for `images > 0` or `finished`. Map results: 201 with `Location`, 400/409 for settings, 503 busy/offline, 409 `NoPaper` with no images, 500 otherwise. `Location` uses the request `Host` header, falling back to the listener address.
- Job thread: call `daemon::capture` with `settings.dpi`, `settings.area`, `!settings.duplex`; callback checks cancel (return `Error::Canceled`), increments `images` per side and notifies, queues `with_orientation_180` JPEGs only for `Format::Jpeg`. After capture, for `Format::Pdf` read the finished PDF and queue it even when `early` is set; set `Completed`, or `Aborted` with `AdfEmpty`/`MediaJam`/`ErrorOccurred`, or `Canceled`; notify; drop the guard. The thread gets a cloned `Arc<Mutex<AdfState>>` and calls the free `note_result` helper from Task 5.
- `HEAD` is answered only for capabilities and status; a HEAD on a job path is 404.
- `NextDocument`: find the job, loop on the condvar; return the next document, or `None` when finished with nothing queued. No fixed deadline. Content type from the job format.
- `DELETE`: mark cancel when the job is processing; 200 for a known job, 404 otherwise.
- Prune finished jobs beyond ten, oldest first, when a new job starts.
- Map `Error::Canceled` to `Canceled`, `Error::NoPaper` to `Aborted/AdfEmpty`, `Error::Feed("paper jam")` and other feed errors to `Aborted/MediaJam`, everything else to `Aborted/ErrorOccurred`.

````markdown
## AirScan

Run with `--airscan` to publish the scanner over eSCL/AirScan. macOS sees it in
````
